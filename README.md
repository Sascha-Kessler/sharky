# Sharky Game

A small browser-based game built with JavaScript, HTML, and CSS.

## Features

- Character movement and attacks
- Enemy AI (PufferFish, JellyFish, Endboss)
- Health, coin, and poison system
- Sound system
- Mobile controls support

## Controls

- Arrow keys → movement
- Space → attack
- B → poison attack

## How to run

Simply open:

index.html

in your browser.

## Project Structure

- models/ → game logic
- js/ → managers (input, sound, ui)
- assets/ → image definitions
- styles/ → CSS
- levels/ → level setup
